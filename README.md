# 📊 Excel Data Analysis Project

## 📌 Project Overview

This project is an Excel-based data analysis project focused on preparing, organizing, and analyzing data using Excel tools and functions.

The workbook includes multiple Excel sheets and practical analysis techniques, with a focus on data handling, formulas, lookups, conditions, formatting, and analysis.

## 🛠️ Excel Skills & Techniques Used

### 🔹 Conditional Formatting
Used to highlight important values, patterns, and conditions in the data and make insights easier to identify visually.

### 🔹 INDEX & MATCH
Used together for flexible lookup and retrieval of values from the dataset.

### 🔹 Excel Conditions
Used conditional logic to evaluate data and return results based on specific criteria.

### 🔹 Data Formatting
Used Excel formatting techniques to organize the data and improve readability and presentation.

### 🔹 Data Analysis & Filtering
Used Excel tools to filter, organize, and analyze records based on different criteria.

### 🔹 Excel Formulas
Used formulas to perform calculations and support the analysis workflow.
